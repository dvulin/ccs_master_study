# Claude skill for the RGN web administrator

`rgn-ccs-master-page` guides Claude through publishing or updating the CCS master page on www.rgn.unizg.hr:
download and check the HTML block from this repository, paste it into the Joomla article, set the redirects and check the live page.

Add it in Claude (claude.ai or the desktop app): Customize > Skills > "+" > Create skill > Upload a skill, and choose
[rgn-ccs-master-page.zip](rgn-ccs-master-page.zip). Then ask Claude, for example: "Update the CCS master page on the RGN site."

Without Claude, read [rgn-ccs-master-page/SKILL.md](rgn-ccs-master-page/SKILL.md): it is a step-by-step guide.
