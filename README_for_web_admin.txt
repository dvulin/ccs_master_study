1. Open the article, switch the editor to code view ("Toggle Editor" or the <> button).
2. Delete the old content and paste everything from CCS_master_page.html (from "START" to "END"). Save.
3. The block has no <script>, <style>, <link>, <form> or <iframe>; only normal HTML with style="..." attributes.
   If it looks plain after saving, the style attributes were filtered: save as a user whose group has
   "No Filtering" (System > Global Configuration > Text Filters).
4. Check on a computer and a phone: the two download buttons, the three email buttons (they open a
   pre-written email to domagoj.vulin@rgn.unizg.hr), the section buttons and the contact links.
